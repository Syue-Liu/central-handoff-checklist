# 中控交接清單

張榮發基金會影音設備交接用的單頁網頁工具。

## 使用方式

開啟 `index.html` 後即可填寫、編輯並複製 LINE 文字或寄出 Email。資料會儲存在目前裝置的瀏覽器中。

## 發布到 GitHub Pages

1. 將這個專案推送到 GitHub。
2. 到 GitHub repository 的 `Settings` > `Pages`。
3. Source 選擇 `Deploy from a branch`。
4. Branch 選擇 `main`，資料夾選擇 `/root`。
5. 儲存後等待 GitHub Pages 產生網址。

## 注意

目前資料使用瀏覽器本機儲存。不同手機、平板或電腦可以開啟同一個網址編輯，但資料不會跨裝置同步。
